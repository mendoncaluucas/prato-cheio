## O que decidimos nesta iteração

**1. Adotar Pull Request revisado já na Unidade 1.** O fluxo de PR só passa a ser
obrigatório na Unidade 2, mas escolhemos usá-lo desde o começo. Cada bloco de trabalho
foi para uma branch própria e entrou na `main` por PR, com o CI verde como condição.

**2. Recortar o escopo do piloto para a fatia vertical H1 → H2 → H3.** Adiamos RN2
(janela de retirada), RN4 (prioridade por proximidade) e RNI3 (devolver à lista sem
coleta), com um critério objetivo: uma regra entra no piloto se for atendível com os
campos que o modelo de dados já tem. A decisão está registrada em `docs/analise.md`.

**3. Trazer a RNI1 para dentro do piloto.** Recusar doação com validade já vencida é
atendível com os campos atuais, então virou o critério CA1.3 — e um sexto teste, que o
template não trazia entre os cinco `it.todo`.

## O que funcionou

- **Escrever os critérios de aceite antes do código.** Quando fomos implementar, os
  testes já estavam definidos: cada critério virou um caso de teste, sem discussão sobre
  o que deveria acontecer.
- **Conferir o documento contra o código.** A revisão pegou três afirmações que tinham
  deixado de ser verdadeiras — um critério citava uma regra que não tratava, faltava o
  critério da validade vencida, e o texto dizia que os critérios casavam um a um com os
  cinco testes, o que era falso.
- **Testar se o teste falha.** Removemos a validação do CA1.3 de propósito para ver o
  teste quebrar. Sem isso, um teste que passa por acidente parece um teste bom.

## O que mudaríamos

- **Mergear mais cedo.** O walking skeleton ficou pronto e testado, mas esperou dias em
  um PR aberto. Nesse período, quem olhasse a `main` via o projeto sem implementação.
- **Distribuir o trabalho entre os quatro.** Nesta iteração as contribuições ficaram
  concentradas em dois integrantes. A Unidade 2 (ADRs e incremento por PR) e a Unidade 3
  (refatoração para PostgreSQL) são mais pesadas que esta.
- **Atenção ao abrir PR a partir de um fork.** O GitHub assume, por padrão, o repositório
  original como destino. Um PR foi aberto por engano no repositório da disciplina.
